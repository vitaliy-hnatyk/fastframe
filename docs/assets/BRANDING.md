# FastFrame visual identity

These are the logo assets approved for the project README.

| File | Purpose |
| --- | --- |
| `fastframe-logo.png` | Cropped presentation of the approved logo, suitable for README and documentation headers. |
| `fastframe-logo-original.png` | Original generated artwork at full resolution (unaltered composition). |
| `fastframe-symbol.png` | Cropped symbol-only region for optional internal mockups. |

The logo uses the wordmark **FastFrame** and the tagline **BUILD FASTER. GO FURTHER.** Keep the original proportions, typography and colors when using it. Cropping is limited to surrounding whitespace; do not stretch or recolor the artwork.

The original asset is raster PNG. A production-ready vector master (SVG) has **not** been created or manually audited. In particular, converting the PNG to SVG does not create a native vector logo. Clear any necessary logo/IP rights before public or commercial release.

Example Markdown:

```markdown
![FastFrame](docs/assets/fastframe-logo.png)
```
